# Portfolio

A personal **Portfolio Website** built with **React**, **Vite**, and **Tailwind CSS**.  
Showcase my projects, skills, and contact information in a clean and responsive design.

---

## Features

- Display my projects with screenshots and descriptions
- Show my skills and technologies
- Responsive design for all devices
- Contact form with email support
- Interactive UI built with Tailwind CSS

---

## Technologies

- **React**  
- **Vite**  
- **Tailwind CSS**  
- **JavaScript (ES6+)**
